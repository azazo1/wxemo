# wxemo v0.1.0

Date: 2026-10-12

首次提供独立的 wxemo CLI 与六个平台/架构的预编译归档.
使用旧 seedsearch 或 Python 脚本的用户请按 Upgrade Notes 切换命令.

## Highlights

- 用同一个 CLI 完成账号发现, seed 搜索和批量解密.
- 保留容器中所有未知区域和尾注, 可逐字节重组去填充明文.
- 下载 Windows, Linux 或 macOS 的 x86_64 / aarch64 预编译归档直接运行.

## Breaking Changes

- 仓库与程序统一改名为 wxemo. 原 seedsearch 和 Python 提取脚本不再作为入口,
  请改用 `wxemo seed` 和 `wxemo extract`.

## Upgrade Notes

1. 保留原始微信数据, 升级和解密不会修改这些文件.
2. 下载对应系统和架构的归档, 使用 `wxemo config init --data-root <目录>` 设置数据根目录.
3. 已知密钥可以用 `wxemo extract --key <密钥>` 直接解密, 否则运行 `wxemo seed`.
4. 使用新输出目录运行 `wxemo extract --manifest`, 并检查摘要中的异常统计.
5. Linux 预编译归档使用 GNU 动态链接, 需要 glibc 2.39 或更新版本;
   较旧系统可使用 Rust 1.88+ 从源码构建.

## Features

- CLI: 增加账号选择, 配置管理, 环境诊断和非交互模式.
- 提取: 支持 PNG, GIF, JPEG 和 WebP 容器拆分, wxgf 原样保留,
  提供完整容器输出和 manifest 清单.

## Bug Fixes

- 提取: 修复未知前缀, 间隙和尾注被静默丢弃的问题.
- 提取: 修复图像载荷内嵌魔数导致重复提取或错误截断的问题.

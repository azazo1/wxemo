# wxemo v0.2.0

Date: 2026-10-12

本版本的主要变化是 seed 搜索新增四种加速后端, 并修正了 Apple Silicon 上
一直用软件 AES 的问题. 另外把 seed 相关操作拆成了独立子命令,
直接运行 `wxemo seed` 的用户请先阅读 Breaking Changes.

## Highlights

- seed 搜索可用 GPU 加速: 新增 `--backend` 参数, 支持 SIMD, CUDA, Metal 和 wgpu.
  CUDA 在 RTX 4060 上相对同机 CPU 实测约 13 倍, Metal 在 M1 上约 6 倍.
- 修正 aarch64 上未启用硬件 AES 的问题, Apple Silicon 的 CPU 搜索提速约 2.5 倍.
- 新增 `seed status` / `import` / `export` / `remove`, seed 可以安全备份和恢复.
- `.wxgf` 可完整导出为 PNG/APNG, 保留动画时序与透明度.

## Breaking Changes

- 命令层级调整: 原先直接执行 `wxemo seed` 就会开始搜索, 现在它只显示用法.
  迁移方式: 改用 `wxemo seed search`, 参数与原来完全一致.
- 后端选择是新增参数, 默认 `auto` 按本机能力挑选, 不指定时行为与旧版本一致.

## Upgrade Notes

1. 升级前如果记不住 seed, 先用旧版本的 `wxemo seed export --out <路径>` 导出一份备份.
2. GPU 后端不改变搜索语义, 命中的 seed 与 key 与 CPU 后端完全一致, 已有密钥记录可直接复用.
3. CUDA 后端默认不编译进发布归档, 需要按使用说明用 `--features cuda` 自行构建.
4. Apple Silicon 用户升级后会直接获得硬件 AES 加速, 无需任何配置.
5. 验证方式: `wxemo seed search --backend auto` 启动日志里会写明实际选中的后端.

## Features

- 搜索: 新增 `--backend <auto|cpu|simd|cuda|metal|wgpu>`.
  `simd` 用 AVX2 或 NEON 一次算多路 MD5; `cuda` 面向 NVIDIA;
  `metal` 是 macOS 原生 compute; `wgpu` 一份 WGSL 覆盖 Metal / Vulkan / DX12.
  显式指定某个后端而本机不支持时直接报错, 不会静默退回标量.
- 搜索: 各后端共用同一套命中判定与复核逻辑, 结果字段与提前退出行为完全一致.
- seed 管理: 新增 `seed status` 查看状态, `seed import` 导入已知值或备份,
  `seed export` 导出备份, `seed remove` 删除记录.
- 提取: `.wxgf` 可完整导出为 PNG 或 APNG, 保留动画帧时序和透明度.
- 诊断: `wxemo doctor` 增加账号发现与目录访问的诊断信息.

## Bug Fixes

- macOS: 主动探测微信容器访问权限, 授权被拒绝时保留系统错误而不是当成目录不存在.
- 搜索: 修正 AVX2 路径在扫描区间上界接近 `u64::MAX` 时的溢出.
- 搜索: 修正 SIMD 批次的十进制位数分段在边界处可能漏候选的问题.

## Performance

- aarch64: 启用 `aes` crate 的 ARMv8 密码学扩展后端.
  该 crate 在 x86_64 上默认做 AES-NI 运行期检测, 在 aarch64 上却需要显式开启,
  不开启会静默使用纯软件实现. M1 上实测从 722 万提升到 1766 万候选每秒.
  Windows ARM 不在启用范围内: 该 crate 只对 macOS 与 Linux 做运行期检测,
  Windows 侧缺少检测兜底, 因此保持软件实现.
- 搜索: 多核标量路径保持不变, 新增的 SIMD 路径在同一环境下约再快 1.3 倍.
